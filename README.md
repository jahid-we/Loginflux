# Pro Login Customizer

> A modern, lightweight WordPress plugin that transforms your default WordPress login page into a stunning glassmorphism experience with dynamic animated Aurora gradient backgrounds.

---

## ✨ Features

- **Fluid Animated Aurora Flow Background**: Mesmerizing multi-stop CSS gradient animation with full color and speed controls.
- **Smart Background Handling**: If a custom background image is uploaded, it takes priority; if no image is present, the animated Aurora gradient takes over seamlessly.
- **WordPress Media Uploader**: Native WP media modal integration for instant logo and background image uploads.
- **Glassmorphism UI**: Frosted glass card with customizable blur, opacity, and border radius.
- **Brand Customization**: Custom logo upload, dimensions (width & height), and subtitle text.
- **WordPress Color Pickers**: Real-time hex color pickers for primary accents, hover states, text, and gradient stops.
- **Modern Admin Dashboard**: Clean 2-column dashboard with tabbed navigation and author sidebar details.
- **Custom CSS Box**: Built-in CSS editor for additional customizations.
- **WordPress.org Ready**: Strict security escaping, sanitization, nonce protection, and internationalization (`pro-login-customizer`).

---

## 🚀 Installation

1. Download or clone this repository to `/wp-content/plugins/pro-login-customizer/`.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Navigate to **Login Page** in the WordPress admin menu to configure your settings.
