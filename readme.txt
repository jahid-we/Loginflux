Customize the WordPress login page with a modern glassmorphism design, custom logo, colors, and background image.

== Description ==

Pro Login Customizer is a lightweight, easy-to-use plugin that completely transforms the default WordPress login page into a modern, beautifully designed interface. 

With a premium glassmorphism aesthetic, you can easily customize the login screen to match your brand's identity right from the WordPress dashboard.

### Features
* **Modern Glassmorphism Design:** A stunning, premium aesthetic out of the box.
* **Custom Logo:** Replace the default WordPress logo with your own.
* **Background Image:** Add a beautiful background image to the login screen.
* **Color Customization:** Change the primary color, hover color, text color, and background color.
* **Border Radius:** Adjust the roundness of the login form container.
* **Live CSS Generation:** Dynamically generates optimized CSS.
* **Translation Ready:** Fully prepared to be translated into any language.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/pro-login-customizer` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to **Login Page** in the WordPress admin menu to configure your custom logo, colors, and background.

== Frequently Asked Questions ==

= Does this plugin modify core WordPress files? =
No, the plugin safely uses standard WordPress hooks to inject the custom styles and settings.

= Can I use it on a Multisite network? =
Yes, it works perfectly on WordPress Multisite.
